The problem

Agents are getting wallets.

What stops an autonomous trading agent from running off with the money?

A policy the agent cannot break.

You sign one rule. The vault enforces it on-chain — not the bot.

How it works
01

Sign one policy

Asset, max notional, blocked hours, expiry. One EIP-712 signature.

02

Delegate the agent

A session key acts only through the vault. Never holds the funds.

03

Violations revert

Checked in Solidity before execution. Off-policy trades revert.

04

Slash & remember

Collateral slashed to the owner. Recorded on a portable identity.
